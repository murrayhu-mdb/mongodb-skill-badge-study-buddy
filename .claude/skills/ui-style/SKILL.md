   ---
   name: ui-style
   description: UI/visual design guidelines for this project
   ---
   
   Use a dark theme with MongoDB-green (#00ED64) accents, consistent with the current app.
   Prefer clean, minimal layouts with generous whitespace over dense/cluttered ones.
   Use consistent spacing, rounded corners, and subtle hover states on interactive elements.
   Avoid generic "AI-generated" look — no default browser styling, no overly bright gradients.
